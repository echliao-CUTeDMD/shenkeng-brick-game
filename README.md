# 深坑築跡｜HTML 桌遊

依《深坑築跡 完整規則書 v1.0》製作，保留原型插畫，支援 2–4 人同一裝置輪流操作。繁體中文、電腦與手機介面；不需安裝套件、建置程序、帳號、API 金鑰或後端。

## 立即遊玩

解壓縮後，用瀏覽器開啟 `index.html`，選擇人數、輸入工匠名字，即可開始。請保留整個資料夾結構。建議正式遊玩使用 GitHub Pages 網址，讓瀏覽器保存進度的行為較一致。

## 上傳 GitHub Pages

1. 在 GitHub 建立儲存庫，例如 `shenkeng-brick-game`。
2. 解壓縮本檔案包，將 `index.html`、`style.css`、`game.js`、`assets` 資料夾、`rules.pdf`、`README.md` 與 `.nojekyll` 放在儲存庫最外層並提交。不要只上傳 ZIP，也不要多包一層資料夾。
3. 開啟儲存庫 **Settings → Pages**。
4. **Source** 選 **Deploy from a branch**；分支選實際存放檔案的分支（通常是 `main`），資料夾選 **/(root)**，按 **Save**。
5. 等待部署完成，開啟 Pages 提供的網站網址。通常為 `https://你的帳號.github.io/shenkeng-brick-game/`。

[GitHub 官方上線說明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

檔案包已備妥，但尚未替你上傳或發布 GitHub。

## 操作

- 抽料：點公開磚卡或「盲抽」。每次拿一張，花一個行動。
- 接案：點任務下方「接案」。任務必須先承接才能興建。
- 料場調度：選「料場調度」，在自己的手牌選兩張，再點想換入的公開磚材。
- 工匠互換：選對象、提供種類、希望取得種類，再把畫面交给對方確認。同意且有指定材料才成交；拒絕不耗行動。
- 興建：點自己承接任務的「興建」，選擇實際付款磚材後確認。可以自由用萬用磚代替已有的指定磚材。
- 超過六張磚材或兩張未完成任務時，必須先棄牌才能繼續。
- 行動用完後按「結束回合」。也可提前放棄剩餘行動。
- 每次交接隱藏秘密手牌；所有工匠的承接任務可在「工匠接案簿」查看。
- 進度保存在本機瀏覽器。重新載入後按「繼續上次遊戲」，仍須通過交接畫面。

## 規則實作

36 張磚材：S 10、TR 10、紅 12、修 4；12 張任務；每人起手三张。隨機決定起始玩家，玩家列由起始玩家起依序顯示。

每回合兩行動，可重複。公開磚材與任務拿取後立即補原位；磚材牌庫不足時洗回棄牌。任務棄牌不洗回。付款一次付清，萬用磚一換一，可同時使用多張。

同區第二張任務立即加三分，每人每區一次。完成至少三區於終局加四分，每人一次。任一人完成第三張任務，或任務牌庫與公開區皆空時，完成當輪即結束，不另加一輪。平手比完成任務印製的 S＋TR 需求，仍同分則並列。

計分直接顯示完整總分，不需手動處理 59→0 的實體棋盤繞圈。卡牌採新版歷史磚圖板（-7），而非含石頭與木頭意象的早期版本（-3）。任務名稱、分值與需求以規則書 v1.0 為準。

## 範圍與檔案

這是現場同機輪流版，不含 AI 對手或不同裝置即時連線。交接遮罩用於現場手牌隱私，並非加密或防作弊系統。不同瀏覽器、装置與網站網址不共用存檔；清除瀏覽器資料會清除存檔。

```
index.html    遊戲入口
style.css     響應式介面
game.js       卡牌資料、規則與操作
assets/       原型插畫的 WebP 裁切素材
rules.pdf     原始完整規則書 v1.0
.nojekyll     靜態網站標記
```

可在 `game.js` 的 `TASKS` 修改任務名稱、區域、材料、分值。規則改動後建議重新開局。

已以 Edge Chromium 測試兩行動、超額棄牌、萬用磚付款、同區／跨區分數、兩種交換、存檔續玩、完成當輪與 390px 手機排版。交付使用你提供的圖像與規則書，未另行授予這些素材的開源授權。
